Detailed Description

A binding table represents a collection of bindings from source types such as FbxObject, or FbxLayerElements to corresponding destinations, usually a third party shader parameters. Binding represents a link between internal object(e.g. FbxObject) and external object(e.g. HLSL shader parameters).

See also
FbxBindingOperator, FbxBindingTableBase
