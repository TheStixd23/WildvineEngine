Detailed Description

Componente que vincula la geometría (Mesh) con sus materiales para renderizar una entidad.

Otorga a una entidad dentro del ECS la capacidad de ser dibujada en pantalla, permitiendo asignar tanto un único material base como una lista de múltiples instancias de material (útil para modelos complejos con varias submallas).
