Detailed Description

Recurso que gestiona la carga, parseo y almacenamiento de geometría 3D.

Model3D hereda de IResource para integrarse en el sistema general de recursos. Soporta la importación de archivos FBX y OBJ extrayendo vértices, índices y referencias a texturas. También implementa un sistema de caché binario local para acelerar significativamente los tiempos de carga en ejecuciones posteriores.
