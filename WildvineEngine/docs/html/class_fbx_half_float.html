Detailed Description

FBX SDK half-float class. Property used to store half-float (16 bit float) number. This class only holds the value in 2 byte buffer (unsigned short). There is no direct math manipulation of this type except for the conversion to/from float. On disk, this type is also saved as an unsigned short.
