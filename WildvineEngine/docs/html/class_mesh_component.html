Detailed Description

Componente ECS que almacena la información de geometría (malla) de un actor.

Un MeshComponent contiene los vértices e índices que describen la geometría de un objeto. Forma parte del sistema ECS y se asocia a entidades como Actor.

La malla incluye:

  • Lista de vértices (posición, normal, UV, etc.).
  • Lista de índices que definen las primitivas (triángulos, líneas).
  • Contadores de vértices e índices.
