Detailed Description

Componente que gestiona las relaciones de parentesco en el grafo de escena.

Permite a una entidad (Entity) actuar como un nodo dentro del Scene Graph, manteniendo referencias directas a una entidad padre y múltiples entidades hijas para la propagación de transformaciones o lógica jerárquica.
