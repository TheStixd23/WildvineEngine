Detailed Description

Encapsula un pase de renderizado fuera de pantalla (off-screen).

Esta clase administra su propio Render Target y Depth Stencil, permitiendo renderizar una escena completa en una textura que posteriormente puede ser leída por un shader o mostrada en la interfaz gráfica del editor (ImGui).
