Detailed Description

Constructor fluido (Builder) para facilitar la creacion de descripciones de Input Layout en DirectX 11.

  • Permite encadenar llamadas para configurar de forma limpia y legible los atributos de los vértices (posición, normales, coordenadas de textura, etc.) o datos de instancia que serán enviados al Input Assembler del pipeline gráfico.
