Detailed Description

This class represents a link between a given FBX node and the associated node in the character hierarchy. It also contains the transform matrix (offset) for the linked character's node.

◆ mRotOrder

int FbxCharacterLink::mRotOrder

Get the PostRotation of this character link.

Get the rotation order of this character link. Note that, for legacy reasons, this member stores the old rotation order values which still have some enum items that have been deprecated in the FBX SDK. For this reason, it is strongly suggested to use the FromFbxEOrder() and ToFbxEOrder() functions to ensure that the FbxEuler::EOrder enum values are always used when querying or setting this property regardless of how it is internally stored.

Ex: 
   mRotOrder = FbxCharacterLink::FromFbxEOrder(FbxEuler::eOrderXYZ)
   FbxEuler::EOrder order = FbxCharacterLink::ToFbxEOrder(mRotOrder)
