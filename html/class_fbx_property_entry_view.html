Detailed Description

FbxPropertyEntryView represents property entry in entry tables. The property can be used as source or destination for the binding entry. Use this class to manipulate binding table's attributes.

Here is a code snippet to show how it used.
FbxProperty lProp;
FbxBindingTable lTable;
FbxBindingTableEntry& lEntry = lBindingTable.AddNewEntry();
FbxPropertyEntryView lView( lEntry, true, true);
lView.SetProperty( lProp.GetName());
